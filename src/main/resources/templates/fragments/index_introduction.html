Rövid bemutató

Az alkalmazás egy egyszerű pénzügyi webes felület. Két fő funkciócsoportja van: az OANDA v20 API-val végzett devizakereskedési műveletek, illetve a Magyar Nemzeti Bank SOAP szolgáltatásából lekért hivatalos árfolyamadatok megjelenítése. A felhasználó böngészőből tekintheti meg a számlaadatait, az aktuális árakat, a nyitott pozíciókat és a historikus gyertyákat, továbbá pozíciót nyithat és zárhat.

A program Maven alapú Spring Boot alkalmazás. A pom.xml alapján webes MVC, Thymeleaf, XML-feldolgozó, SOAP és HTTP kliens komponenseket használ. A projekt Java 25-re van beállítva.
